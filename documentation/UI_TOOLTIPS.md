# UI Tooltips Engine

To make the platform more accessible for individuals with limited financial knowledge, we have implemented a pure JavaScript/CSS tooltip engine for explaining metrics and plots across the application.

## How it works

The tooltip engine uses a single, globally attached event listener in `static/js/main.js` (`initInfoTooltips()`). It looks for `<button>` elements with the class `info-btn` and reads specific `data-t-*` attributes to construct a rich, styled tooltip popup dynamically.

This avoids the need for heavy external libraries (like Bootstrap tooltips or Tippy.js) and keeps the application lightweight and responsive.

## Usage Guide

To add a tooltip to any metric, icon, or label, simply add an info button next to it:

```html
<button class="info-btn" 
        aria-label="Metric Name" 
        data-t-title="Full Metric Name" 
        data-t-what="What this metric is in plain English." 
        data-t-interp="How to interpret it (e.g., Higher is better).">ⓘ</button>
```

### Available Attributes

*   `data-t-title` *(Optional)*: The bold title at the top of the tooltip. If omitted, the `aria-label` is used as a fallback.
*   `data-t-what`: A short description explaining **what** the metric/item is.
*   `data-t-interp` *(Optional)*: Interpretation guide (e.g., "Higher values indicate more risk"). Supports basic HTML like `<strong>`.
*   `data-t-formula` *(Optional)*: If a mathematical formula or calculation is relevant, place it here.
*   `data-t-note` *(Optional)*: A disclaimer or important note at the bottom of the tooltip (e.g., "Data may be delayed by 24h").
*   `data-t-range` *(Optional)*: Used to display a horizontal color-coded range bar (good/ok/bad). It accepts a JSON array string.
    *   *Example:* `data-t-range='[{"dot":"good","label":"< 1%","text":"Low cost"},{"dot":"bad","label":"> 2%","text":"Expensive"}]'`

## Example Implementations

### Basic Explanation (Standard)
```html
<div class="metric-key">AUM
  <button class="info-btn" aria-label="AUM" data-t-title="Assets Under Management (AUM)" data-t-what="The total amount of money managed by this mutual fund.">ⓘ</button>
</div>
```

### With Interpretation (Advanced)
```html
<div class="metric-key">Alpha
  <button class="info-btn" aria-label="Alpha" data-t-title="Jensen's Alpha" data-t-what="Measures the extra return generated by the fund manager compared to the benchmark index, given the amount of risk taken." data-t-interp="<strong>Positive Alpha (>0):</strong> The manager added value and beat the market. Higher is better.">ⓘ</button>
</div>
```

## Styling and Layout

*   **CSS:** The tooltip styles are defined in `static/css/main.css` under the `/* --- Tooltips --- */` section.
*   **Positioning:** The JavaScript automatically detects screen edges and flips the tooltip upward or to the side if there isn't enough space below or to the right of the button.
*   **Mobile Support:** On mobile devices, the tooltip is constrained to the viewport width, ensuring it never causes horizontal scrollbars or gets cut off.
