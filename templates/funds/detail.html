Scoring Framework

This scorecard uses a category-normalized, multi-factor model to evaluate funds across 5 independent pillars. Each pillar is scored 0–100 and combined using fixed weights:

  • Performance (30%) — Trailing CAGR (1Y/3Y/5Y), rolling win rate, excess return vs benchmark.
  • Risk / Stability (28%) — Sortino ratio, max drawdown, downside capture ratio, Sharpe ratio. Emphasises downside control over total volatility.
  • Cost (12%) — Expense ratio vs category-type norms, AUM size factor.
  • Composition (15%) — Top-10 concentration, total holdings count, sector HHI (diversification index).
  • Red Flag Penalty (up to −15 pts) — Structural risks deducted from the composite: missing benchmark, very high ER, low AUM, extreme concentration, insufficient data.

Normalization & Fallbacks

Each metric is linearly normalized to [0, 100] using fixed thresholds calibrated for the Indian mutual fund market. When data is missing for a pillar, the score for that pillar is excluded and weights are redistributed across available pillars. The confidence level (Rated / Provisional / Unrated) reflects data coverage.

Category Rank

The fund is ranked among peers in the same SEBI category (Direct/Regular separated) using pre-computed analytics stored in our database. Peer count reflects funds in our database, not the total universe.
