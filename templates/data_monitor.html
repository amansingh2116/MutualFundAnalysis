ℹ️ How the Pipeline Works

🏛️
NAV Data Source
Daily NAVs are fetched from mfapi.in (AMFI mirror). Published by AMFI at ~8 PM IST, ingested at 2 AM IST daily. Incremental fetch — only new rows are added.
⚙️
Analytics Engine
After NAV ingestion, rolling returns (1Y/3Y/5Y), Sharpe, Sortino, Beta, Alpha, drawdowns are computed per fund. Skipped automatically on weekends when no new NAV arrives.
🔄
Self-Completing Weekly Cycle
Pipeline runs every 6 hours via GitHub Actions (free for public repos). Each run processes stale funds in AMFI-code order using --resume --resume-hours=167 (7-day window). After ~7–9 runs (~2–3 days), all {{ total_dg }} funds are refreshed. Remaining runs that week find 0 stale funds and complete in under 5 minutes. Next Monday: the 7-day window expires and the full cycle restarts automatically.
